# WHY THE VALIDATOR IS LONGER THAN THE TERRAFORM
#
# The Terraform is three resources and barely an afternoon. The hard part of
# this week is not disabling an account - it is knowing which accounts are safe
# to disable, and proving afterwards that nothing depended on them.
#
# So validate.sh checks four things the apply cannot: that the accounts are
# disabled and NOT deleted, that key creation is blocked on BOTH constraint
# generations, that no user-managed key exists anywhere, and when each surviving
# account last authenticated.
#
# The last one REPORTS rather than fails. An account idle this week may be
# seasonal, and a check that cries wolf is a check people learn to ignore.
